
# CRM SQL Analysis (Leads & Customers)

🚧 **Work in progress** — I'm currently practicing SQL queries before building the dashboard.

## About this project

This is a practice project analyzing a synthetic CRM dataset with two tables: `customers` (100 rows) and `leads` (1000 rows). The goal is to practice SQL data analysis and then visualize the results in a Power BI dashboard.

## Tools used

- MySQL — data storage and querying
- Power BI — dashboard (coming soon)

## Dataset

- `data/crm_leads_customers_mysql.sql` — table schema + sample data (synthetic/practice data, not real customers)
- Tables: `customers`, `leads`
- Note: leads and customers are independent record sets in this dataset — there's no direct link (e.g., matching email) between a lead and a converted customer.
